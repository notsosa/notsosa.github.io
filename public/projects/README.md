# Imágenes de proyectos

Usa una carpeta por proyecto y coloca dentro sus fotografías o capturas. Elige
nombres cortos y descriptivos, por ejemplo `robot-seguidor/portada.jpg`, y
procura que cada imagen pese menos de 1 MB para que el portafolio cargue rápido.
Los videos pueden guardarse en la misma carpeta; usa MP4 y procura mantenerlos
breves y por debajo de 10 MB.
